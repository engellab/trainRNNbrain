# N = 4,000 seed 1 on the maze died at update 1,050 and is resumed from its update-1,000 checkpoint

**Date:** 2026-11-05 08:01
**Issue:** #3 (the maze size series)

## What happened

The three N = 4,000 ReLU maze runs on Della (array 16883344, tasks 21 to 23, code 9dce02e) were at
update 1,000 to 1,400 of 2,000 with no restores when task 21 (seed 1) stopped: three rollouts in a
row were not finite at about update 1,050, which on that code raises and ends the run ("the rollout
was not finite 3 times in a row"). The code at 9dce02e restores the last finite weights before each
retry; the fallback to the last checkpoint's weights (2afc209) did not exist on Della yet. The run
had saved a checkpoint at update 1,000 (success 0.42, probe success 0.50, 773 of 4,000 units
active, learning rate 2.9e-4 on the ramp of 1e-3 (100/4000)^(1/3)). Seeds 2 and 3 are at update
1,400 with no restores and keep running.

## What was done

- A Della worktree `~/trainRNNbrain_rlmaze4` at 2afc209 (the current main: continuation path,
  snapshot fallback, both file layouts read).
- Seed 1 continued from the checkpoint with the launcher's continuation mode, 3,000 further updates
  so the chain ends at update 4,000 like the planned 2,000 + 2,000 of seeds 2 and 3:

```
REPO=~/trainRNNbrain_rlmaze4 PARENT_ROOT=~/trainRNNbrain/data/trained_RNNs_rl_maze/Maze_suite \
EXTRA_UPDATES=3000 INIT_ADAM=false sbatch --array=21 --time=36:00:00 --constraint=gpu80 \
slurm/rl_maze_suite_della.slurm      # Della job 16907630
```

  INIT_ADAM=false because the parent was written before the Adam state file existed, so Adam starts
  afresh and the 50-update ramp runs again, as in the N = 2,000 continuations on Spock (7384301).

## What differs from seeds 2 and 3

Seed 1's chain restarts Adam at update 1,000 and then runs 3,000 updates on one optimiser state;
seeds 2 and 3 will restart Adam at update 2,000. The read-out (common.maze_load_runs) joins each
chain by `paths.init_from`; the join point is visible in the Progress records (the learning-rate
ramp). The seed-1 chain is labelled in the read-out as resumed at 1,000.

## Falsifier

If the seed-1 continuation is also stopped by non-finite rollouts, the forward-dynamics blow-up at
N = 4,000 is not a first-steps artefact of Adam (which the ramp addresses) and the snapshot fallback
is the only guard; the paper then reports N = 4,000 as trained with restores, with the count.
